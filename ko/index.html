Windows용 기한·계약 폴더

기한은 한눈에, 계약서는 손 닿는 곳에.

계약서, 청구서, 중요한 서류를 내 PC 한곳에 모으세요. 사본을 보관하고, 오프라인으로 텍스트를 인식하고, 기한을 놓치지 마세요. 계정도 클라우드도 필요 없습니다.

  • 24,99 € 일회성 · 구독 없음
  • 계정 없이 오프라인
  • 데이터는 내 PC에 보관

Microsoft Store 출시 예정사용 방법

세 단계로 정리되는 보관함

  1. 1

    문서를 끌어다 놓기

    PDF, 스캔 파일, 휴대폰 사진을 끌어서 놓거나 폴더째로 추가하세요. Docloft가 사본을 검증하고 중복 파일을 찾아냅니다.

  2. 2

    확인하고 정리하기

    오프라인으로 텍스트를 인식하고, 제안된 종류·날짜·발신인을 확인한 뒤 태그를 추가하세요. 무엇을 저장할지는 직접 결정합니다.

  3. 3

    찾고 기억하기

    단어의 앞부분이나 악센트 없이도 검색할 수 있습니다. 기한을 추가하고 Windows 알림을 며칠 전에 받을지 선택하세요.

중요한 기능을 가까이에

비용을 한눈에

계약별 월 비용과 연 비용, 그리고 앞으로 90일 안에 해지할 수 있는 계약을 확인할 수 있습니다.

1분 만에 해지 통지서

계약 번호와 날짜가 들어가며 확인, 복사, 이메일 발송을 바로 할 수 있습니다. 직접 보낸 것만 전송됩니다.

기한을 한눈에

해지일, 계약 종료일, 보증, 결제, 만료일: 지난 항목과 앞으로 30일을 확인할 수 있습니다.

템플릿이 있는 해지 계산기

계약 종료일에서 해지 예고 기간을 빼면 해지 기한이 나옵니다. 휴대폰, 전기, 보험 템플릿이 일반적인 값을 미리 채워 주며, 계약서와 비교해 확인합니다.

휴대폰에서도 받는 알림

원하는 사전 알림 일수로 Windows 알림을 설정하세요. 항상 최신 상태인 캘린더 파일로 기한을 Outlook과 휴대폰에서도 볼 수 있습니다.

오프라인 텍스트 인식과 검색

Windows OCR로 스캔 파일과 사진을 검색할 수 있게 하며, 단어의 앞부분이나 악센트 없는 표기로도 찾을 수 있습니다.

보관함은 내 것으로 남습니다

로컬 데이터

클라우드, 계정, 광고, 추적이 없습니다. 문서는 디스크에 있는 일반 파일입니다.

손대지 않는 원본

Docloft는 검증된 사본으로 작업합니다. 원본 파일은 변경, 이동, 삭제되지 않습니다.

백업과 내보내기

Microsoft Store에서 24,99 € 일회성 구매이며 구독은 없고 버전 1 업데이트가 포함됩니다. 환불에는 Microsoft Store 약관이 적용됩니다.

백업을 암호화할 수 있나요?

네. 비밀번호(AES-256)로 암호화할 수 있으며 매주 자동 백업에도 적용됩니다. 비밀번호가 없으면 백업을 열 수 없으며, 저희도 열 수 없습니다. 안전하게 보관하세요.

Docloft 미리 보기

가져오기부터 백업까지: 텍스트를 확인하고, 해지 기한을 계산하고, 확정한 기한을 놓치지 마세요.

가격

Microsoft Store에서 24,99 € 일회성 구매이며 구독은 없습니다.

버전 1 업데이트가 포함됩니다. 백업(원하면 암호화)과 내보내기는 앱에 포함되어 있으며, 데이터는 내 것입니다.

Microsoft Store 출시 예정

자주 묻는 질문

Docloft 가격은 얼마인가요?

Microsoft Store에서 24,99 € 일회성 구매, 구독 없음, 버전 1 업데이트 포함. 환불은 Microsoft Store 약관을 따릅니다.

원본이 보존되나요?

네. Docloft는 검증된 사본을 저장하고 원본 파일은 기존 위치에 그대로 둡니다.

파일은 어디에 저장되나요?

PC의 %LOCALAPPDATA%\MinhStudios\Docloft 아래에 로컬로 저장됩니다. 문서 사본은 디스크의 일반 파일이며 클라우드 동기화는 없습니다.

텍스트 인식은 어떻게 작동하나요?

Windows OCR과 설치된 Windows 언어 팩으로 로컬에서 실행됩니다. 설치된 Tesseract를 대체 수단으로 사용할 수 있습니다.

앱이 꺼져 있어도 알림이 표시되나요?

Windows는 앱이 닫혀 있어도 예약된 알림을 표시할 수 있습니다. Windows 알림을 켜세요. 400일 이내에 최대 200개의 알림 시점이 예약됩니다. 일정을 갱신하려면 앱을 주기적으로 여세요. 날짜는 입력하신 내용에 따르므로 확인해 주세요.

Docloft가 해지 예고 기간을 확인해 주나요?

아니요. 앱은 입력하신 내용을 저장하고 그것으로 계산합니다. 법정 기한, 계약 조건, 보관 의무는 확인하지 않으며 법률 또는 세무 자문을 제공하지 않습니다.

백업을 암호화할 수 있나요?

네, 비밀번호(AES-256)로 암호화할 수 있으며 매주 자동 백업도 포함됩니다. 비밀번호가 없으면 누구도 백업을 열 수 없습니다. 저희도 마찬가지입니다. 안전한 곳에 적어 두세요.
