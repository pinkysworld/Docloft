최종 업데이트: 2026년 11월 2일

앱은 데이터를 수집하지 않습니다

Minh Nguyen Studios는 Docloft를 통해 문서나 사용 데이터를 받지 않습니다. 계정, 광고, 원격 측정, 분석, 클라우드 동기화가 없습니다.

로컬 저장과 텍스트 인식

문서 사본과 데이터베이스는 PC의 %LOCALAPPDATA%\MinhStudios\Docloft 아래에 로컬로 저장됩니다. 텍스트 인식은 Windows OCR 또는 설치된 Tesseract로 로컬에서 실행됩니다. Windows 계정과 드라이브를 보호하세요. 데이터, 백업, 내보내기는 직접 기기에서 삭제합니다.

내보내기와 다른 앱

ZIP 백업, 폴더 및 CSV 내보내기, ICS 캘린더 파일에는 사용자의 데이터가 들어 있습니다. 누구와 공유할지는 직접 결정하세요. 문서 열기는 해당 앱의 규정을, 구매는 Microsoft Store의 규정을 따릅니다.

이 웹사이트는 GitHub Pages(GitHub, Inc.)에서 호스팅됩니다. 방문 시 GitHub는 페이지 제공과 남용 방지에 필요한 IP 주소 등의 연결 데이터를 처리하며, 데이터가 미국으로 전송될 수 있습니다. 법적 근거는 사이트를 안전하게 제공하려는 당사의 정당한 이익(GDPR 제6조 제1항 f호)입니다. 자세한 내용은 아래 링크된 GitHub 개인정보 처리방침을 참조하세요. 이 사이트 자체는 쿠키, 추적기, 외부 스크립트나 글꼴을 사용하지 않습니다.
