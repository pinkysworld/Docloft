Privasi

Terakhir diperbarui: 2 November 2026

Aplikasi tidak mengumpulkan data

Minh Nguyen Studios tidak menerima dokumen atau data penggunaan melalui Docloft. Tidak ada akun, iklan, telemetri, analitik, atau sinkronisasi cloud.

Penyimpanan lokal dan pengenalan teks

Salinan dokumen dan basis data disimpan secara lokal di PC-mu di %LOCALAPPDATA%\MinhStudios\Docloft. Pengenalan teks berjalan secara lokal dengan Windows OCR atau Tesseract yang terpasang. Lindungi akun Windows dan drive-mu. Kamu sendiri yang menghapus data, cadangan, dan ekspor di perangkatmu.

Ekspor dan aplikasi lain

Cadangan ZIP, ekspor folder dan CSV, serta file kalender ICS berisi datamu. Kamu yang memutuskan dengan siapa membagikannya. Membuka dokumen tunduk pada aplikasi terkait; pembelian tunduk pada Microsoft Store.

Situs web ini

Situs web ini di-hosting di GitHub Pages (GitHub, Inc.). Saat kamu mengunjunginya, GitHub memproses data koneksi yang diperlukan untuk mengirimkan halaman dan melindungi dari penyalahgunaan, seperti alamat IP-mu; data dapat ditransfer ke AS. Dasar hukumnya adalah kepentingan sah kami dalam menyediakan situs secara aman (Pasal 6(1)(f) GDPR). Rinciannya ada di pernyataan privasi GitHub yang ditautkan di bawah. Situs web ini sendiri tidak memasang cookie dan tidak menggunakan pelacak, skrip eksternal, atau font eksternal.

Kontak

Jika kamu mengirim email kepada kami, kami memproses pesanmu untuk menjawab pertanyaanmu. Jangan kirim dokumen rahasia atau file cadangan. Pengendali: Michel Nguyen, Minh Nguyen Studios, Windmühlenstr. 74, 07937 Zeulenroda-Triebes, Jerman.
