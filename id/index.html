Folder tenggat dan kontrak untuk Windows

Tenggat selalu terlihat, kontrak selalu siap.

Kontrak, tagihan, dan surat penting bersama di PC-mu. Simpan salinan, kenali teks secara offline, dan pantau tenggatmu. Tanpa akun, tanpa cloud.

  • Sekali bayar 24,99 € · tanpa langganan
  • Tanpa akun, offline
  • Data tetap di PC-mu

Segera hadir di Microsoft StoreCara kerja

Arsip rapi dalam tiga langkah

  1. 1

    Masukkan dokumenmu

    Tambahkan PDF, pindaian, dan foto ponsel dengan seret dan lepas atau satu folder sekaligus. Docloft memverifikasi salinan dan mendeteksi file duplikat.

  2. 2

    Periksa dan atur

    Kenali teks secara offline, periksa saran jenis, tanggal, dan pengirim, lalu tambahkan tag. Kamu yang memutuskan apa yang disimpan.

  3. 3

    Temukan dan ingat

    Cari dengan awal kata atau tanpa aksen. Tambahkan tenggat dan pilih waktu pengingat notifikasi Windows.

Yang penting, selalu dekat

Biaya sekilas

Berapa biaya kontrakmu per bulan dan per tahun – dan mana yang bisa kamu putuskan dalam 90 hari ke depan.

Surat pemutusan dalam semenit

Dengan nomor kontrak dan tanggal, siap diperiksa, disalin, atau dikirim lewat email. Tidak ada yang terkirim kecuali kamu sendiri yang mengirim.

Tenggat sekilas

Batas pemutusan, akhir kontrak, garansi, pembayaran, dan tanggal kedaluwarsa: lihat yang terlambat dan 30 hari ke depan.

Kalkulator pemberitahuan dengan templat

Akhir kontrak dikurangi masa pemberitahuan menghasilkan batas pemutusanmu. Templat untuk ponsel, listrik, atau asuransi mengisi nilai yang lazim – kamu mencocokkannya dengan kontrak.

Pengingat, juga di ponsel

Notifikasi Windows dengan waktu pengingat pilihanmu. File kalender yang selalu mutakhir membawa tenggat ke Outlook dan ponselmu.

Pengenalan teks dan pencarian offline

Windows OCR membuat pindaian dan foto dapat dicari – dengan awal kata dan tanpa aksen.

Arsipmu tetap milikmu

Data lokal

Tanpa cloud, akun, iklan, atau pelacakan. Dokumenmu adalah file biasa di disk-mu.

File asli tetap utuh

Docloft bekerja dengan salinan terverifikasi. File aslimu tidak pernah diubah, dipindahkan, atau dihapus.

Cadangan dan ekspor

Selama digunakan, aplikasi membuat paling banyak satu cadangan basis data per hari. Cadangan ini tidak berisi file dokumen; buat cadangan ZIP lengkap dan simpan salinannya di drive lain.

Melihat isi Docloft

Dari impor hingga cadangan: periksa teks, hitung batas pemutusan, dan pantau tenggat yang sudah dikonfirmasi.

Pertanyaan umum

Berapa harga Docloft?

Sekali bayar 24,99 € di Microsoft Store, tanpa langganan, pembaruan untuk versi 1 sudah termasuk. Pengembalian dana mengikuti ketentuan Microsoft Store.

Apakah file asliku tetap terjaga?

Ya. Docloft menyimpan salinan terverifikasi dan membiarkan file asli tidak berubah di lokasinya.

Di mana file-ku disimpan?

Secara lokal di PC-mu di %LOCALAPPDATA%\MinhStudios\Docloft. Salinan dokumen adalah file biasa di disk-mu; tidak ada sinkronisasi cloud.

Bagaimana cara kerja pengenalan teks?

Berjalan secara lokal dengan Windows OCR dan paket bahasa Windows yang terpasang. Tesseract yang terpasang dapat digunakan sebagai cadangan.

Apakah pengingat muncul saat aplikasi ditutup?

Windows dapat menampilkan pengingat terjadwal saat aplikasi ditutup. Aktifkan notifikasi Windows. Hingga 200 waktu pengingat direncanakan dalam 400 hari; buka aplikasi secara rutin untuk memperbarui jadwal. Tanggal berasal dari masukanmu; mohon periksa.

Apakah Docloft memeriksa masa pemberitahuanku?

Tidak. Aplikasi menyimpan datamu dan menghitung berdasarkan data itu. Aplikasi tidak memeriksa tenggat hukum, ketentuan kontrak, atau kewajiban penyimpanan dan tidak memberikan nasihat hukum atau pajak.

Bisakah aku mengenkripsi cadangan?

Ya, dengan kata sandi (AES-256), termasuk cadangan otomatis mingguan. Tanpa kata sandi cadangan tidak dapat dibuka – bahkan oleh kami. Simpan di tempat yang aman.
