プライバシー

更新日：2026年11月2日

アプリはデータを収集しません

Minh Nguyen StudiosはDocloft経由で書類や利用状況を受け取りません。アカウント、広告、テレメトリー、分析、クラウド同期はありません。

ローカル保存と文字認識

コピーとデータベースはPC内の%LOCALAPPDATA%\MinhStudios\Docloftに保存されます。文字認識はWindows OCRまたはインストール済みTesseractでローカル処理します。Windowsアカウントとディスクを保護してください。データ、バックアップ、出力ファイルは端末上でご自身で削除します。

出力と他のプログラム

ZIPバックアップ、フォルダー・CSV出力、ICSカレンダーにはあなたのデータが含まれます。共有先は自分で決められます。書類を開く際は利用するプログラム、購入時はMicrosoft Storeの規定が適用されます。

このウェブサイト

このウェブサイトは GitHub Pages（GitHub, Inc.）でホストされています。アクセス時、GitHub はページの配信と不正利用の防止に必要な接続データ（IPアドレスなど）を処理し、データが米国に転送される場合があります。法的根拠は、サイトを安全に提供するという当方の正当な利益（GDPR第6条1項f）です。詳細は下記リンクの GitHub プライバシーステートメントをご覧ください。本サイト自体は Cookie、トラッカー、外部スクリプト、外部フォントを使用しません。
