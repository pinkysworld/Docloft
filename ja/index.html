Windows用の契約書・期限管理アプリ

期限を把握し、契約書をすぐ手元に。

契約書、請求書、大切な手紙をPCでひとまとめに。コピーを保存し、オフラインで文字を認識して期限を管理できます。アカウントもクラウドも不要です。

  • 24,99 €の買い切り・定期購読なし
  • アカウント不要・オフライン
  • データはPC内に保存

Microsoft Storeで近日公開使い方を見る

3ステップで書類を整理

  1. 1

    書類を追加

    PDF、スキャン画像、写真をドラッグ＆ドロップするか、フォルダーごと追加します。コピーを検証し、同一ファイルの重複を検出します。

  2. 2

    確認して整理

    オフラインで文字を認識し、提案された種類、日付、差出人を確認してタグを追加します。保存内容は自分で決められます。

  3. 3

    検索して期限を管理

    単語の先頭部分やアクセント記号なしで検索できます。期限を入力し、Windows通知を何日前に表示するか設定します。

大切な情報をすぐ手元に

費用を一目で

契約ごとの月額・年額の費用と、今後90日以内に解約できる契約を確認できます。

1分で作る解約通知書

契約番号と日付入りで、確認・コピー・メール送信の準備ができます。自分で送信したものだけが送られます。

期限を一覧表示

解約期限、契約終了、保証、支払い、有効期限。期限切れと今後30日分を一覧で確認できます。

テンプレート付き解約期限計算

契約終了日から予告期間を引いて解約期限を計算。携帯電話・電気・保険のテンプレートが一般的な値を入力済みにします。契約書と照らして確認してください。

スマートフォンにも届くリマインダー

Windows通知を好きなタイミングで設定。常に最新のカレンダーファイルで、期限をOutlookやスマートフォンにも取り込めます。

オフライン文字認識と検索

Windows OCRでスキャン画像や写真を検索可能にし、単語の先頭部分やアクセント記号なしでも探せます。

データはあなたのもの

ローカル保存

クラウド、アカウント、広告、トラッキングはありません。書類はディスク上の通常のファイルです。

元のファイルを保持

検証したコピーを使います。元のファイルを変更、移動、削除しません。

バックアップと出力

Microsoft Storeで24,99 €の買い切りです。定期購読はなく、バージョン1のアップデートを含みます。返金にはMicrosoft Storeの条件が適用されます。

バックアップを暗号化できますか？

はい。パスワード（AES-256）で暗号化でき、毎週の自動バックアップにも対応します。パスワードがないとバックアップは開けません。当方でも開けません。安全な場所に控えてください。

取り込みからバックアップまで：本文を確認し、解約日を計算して、確認した期限を管理します。

Microsoft Storeで24,99 €の買い切りです。定期購読はありません。

バージョン1のアップデートを含みます。バックアップ（希望すれば暗号化）とエクスポートはアプリの機能に含まれ、データはあなたのものです。

よくある質問

Docloftの価格は？

Microsoft Storeで24,99 €の買い切り。定期購読はなく、バージョン1のアップデートを含みます。返金はMicrosoft Storeの規約に従います。

元のファイルは残りますか？

はい。検証したコピーを保存し、元のファイルは元の場所で変更せずに保持します。

ファイルはどこに保存されますか？

PC内の%LOCALAPPDATA%\MinhStudios\Docloftに保存されます。書類のコピーはディスク上の通常のファイルで、クラウド同期はありません。

文字認識はどう動きますか？

Windows OCRとインストール済みの言語パックを使い、PC内で処理します。インストール済みのTesseractを代替として利用できます。

アプリを閉じていても通知されますか？

Windows はアプリ終了中も予約済みの通知を表示できます。Windows の通知を有効にしてください。400日以内の最大200件の通知を予約します。定期的にアプリを開き、予約を更新してください。日付は入力内容に基づきます。確認してください。

解約期限を確認してくれますか？

いいえ。入力した情報を保存し、その情報で計算します。法定期限、契約条件、保存義務を確認するものではなく、法律・税務の助言も行いません。

バックアップを暗号化できますか？

はい、パスワード（AES-256）で暗号化できます。毎週の自動バックアップも対象です。パスワードがないと誰も開けません。私たちも開けません。安全な場所に控えてください。
