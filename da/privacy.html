Privatliv

Sidst opdateret: 2. november 2026

Appen indsamler ingen data

Minh Nguyen Studios modtager ingen dokumenter eller brugsdata gennem Docloft. Der er ingen konto, reklamer, telemetri, analyse eller skysynkronisering.

Lokal lagring og tekstgenkendelse

Dokumentkopier og databasen gemmes lokalt på din pc under %LOCALAPPDATA%\MinhStudios\Docloft. Tekstgenkendelsen kører lokalt med Windows OCR eller en installeret Tesseract. Beskyt din Windows-konto og dit drev. Du sletter selv data, sikkerhedskopier og eksporter på din enhed.

Eksporter og andre apps

ZIP-sikkerhedskopier, mappe- og CSV-eksporter og ICS-kalenderfiler indeholder dine data. Du bestemmer, hvem du deler dem med. Åbning af dokumenter sker i den pågældende app; køb sker via Microsoft Store.

Dette websted

Dette websted hostes på GitHub Pages (GitHub, Inc.). Ved besøg behandler GitHub forbindelsesdata, der er nødvendige for at levere siderne og beskytte mod misbrug, f.eks. din IP-adresse; data kan blive overført til USA. Retsgrundlaget er vores legitime interesse i sikker levering (art. 6, stk. 1, litra f, GDPR). Detaljer findes i GitHubs privatlivserklæring, der er linket nedenfor. Webstedet bruger ingen cookies, trackere, eksterne scripts eller skrifttyper.

Kontakt

Hvis du sender os en e-mail, behandler vi din besked for at besvare din henvendelse. Send ikke fortrolige dokumenter eller sikkerhedskopier. Dataansvarlig: Michel Nguyen, Minh Nguyen Studios, Windmühlenstr. 74, 07937 Zeulenroda-Triebes, Tyskland.
