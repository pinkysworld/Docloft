Privacidad

Actualizado: 2 de noviembre de 2026

La app no recopila datos

Minh Nguyen Studios no recibe documentos ni datos de uso a través de Docloft. Sin cuenta, publicidad, telemetría, análisis ni sincronización en la nube.

Almacenamiento y OCR locales

Las copias y la base de datos están en tu PC en %LOCALAPPDATA%\MinhStudios\Docloft. El OCR usa Windows o Tesseract instalado localmente. Protege tu cuenta Windows y tu disco. Tú eliminas datos, copias y exportaciones de tu dispositivo.

Exportaciones y otros programas

Las copias ZIP, carpetas, CSV y calendarios ICS contienen tus datos. Tú decides con quién compartirlos. La apertura depende del programa utilizado; la compra, de Microsoft Store.

Este sitio

Este sitio se aloja en GitHub Pages (GitHub, Inc.). Al visitarlo, GitHub trata los datos de conexión necesarios para servir las páginas y protegerlas contra abusos, como tu dirección IP; los datos pueden transferirse a EE. UU. La base jurídica es nuestro interés legítimo en ofrecer el sitio de forma segura (art. 6.1.f RGPD). Los detalles están en la declaración de privacidad de GitHub enlazada abajo. El sitio no usa cookies, rastreadores, scripts ni fuentes externas.

Contacto

Tratamos tu correo para responder a tu consulta. No envíes documentos confidenciales ni copias de seguridad. Responsable: Michel Nguyen, Minh Nguyen Studios, Windmühlenstr. 74, 07937 Zeulenroda-Triebes, Alemania.
