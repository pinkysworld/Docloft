三個步驟打造井然有序的封存

  1. 1

    放入您的文件

    以拖放或整個資料夾的方式新增 PDF、掃描檔和手機照片。Docloft 會驗證副本並偵測重複檔案。

  2. 2

    檢查並整理

    離線辨識文字，檢查建議的類型、日期和寄件者，並加上標籤。儲存什麼由您決定。

  3. 3

    搜尋與提醒

    依詞語開頭或不分重音符號搜尋。新增期限，並選擇 Windows 通知的提前時間。

重要的事，近在手邊

費用一目了然

您的合約每月和每年花費多少，以及哪些合約可在未來 90 天內終止。

一分鐘完成終止信

附合約編號和日期，可直接檢查、複製或透過電子郵件寄送。除非您親自寄出，否則不會寄出任何內容。

期限一目了然

最晚終止日、合約到期、保固、付款和有效期限：查看逾期項目和未來 30 天。

附範本的終止期限計算器

合約到期日減去終止通知期，即得最晚終止日。手機、電力或保險範本會預填一般數值，由您與合約比對。

提醒，手機上也收得到

Windows 通知，提前時間由您選擇。持續更新的行事曆檔可將期限帶到 Outlook 和您的手機。

離線文字辨識與搜尋

Windows OCR 讓掃描檔和照片可供搜尋，可依詞語開頭且不分重音符號搜尋。

您的封存始終屬於您

本機資料

沒有雲端、帳號、廣告或追蹤。您的文件是磁碟上的一般檔案。

原始檔案不受影響

Docloft 使用經驗證的副本。您的原始檔案絕不會被變更、移動或刪除。

備份與匯出

使用期間，App 每天最多建立一份資料庫備份，其中不含文件檔案；請建立完整的 ZIP 備份，並在另一個磁碟機上保留一份副本。

一窺 Docloft

從匯入到備份：檢查文字、計算最晚終止日，並掌握已確認的期限。

常見問題

Docloft 多少錢？

在 Microsoft Store 一次性 24,99 €，無需訂閱，包含第 1 版的更新。退款依 Microsoft Store 條款辦理。

我的原始檔案會保留嗎？

會。Docloft 會歸檔一份經驗證的副本，原始檔案則原封不動留在原位置。

我的檔案存放在哪裡？

存放在您電腦本機的 %LOCALAPPDATA%\MinhStudios\Docloft 下。文件副本是磁碟上的一般檔案；沒有雲端同步。

文字辨識如何運作？

使用 Windows OCR 和已安裝的 Windows 語言套件在本機執行。已安裝的 Tesseract 可作為備用。

App 關閉時會顯示提醒嗎？

App 關閉時，Windows 可以顯示已排程的提醒。請啟用 Windows 通知。最多會在 400 天內排程 200 個提醒時間；請定期開啟 App 以更新排程。日期來自您的輸入，請自行檢查。

Docloft 會檢查我的終止通知期嗎？

不會。App 儲存您的資料並依此計算。它不檢查法定期限、合約條款或保存義務，也不提供法律或稅務建議。

我可以加密備份嗎？

可以，使用密碼（AES-256），每週自動備份也適用。沒有密碼就無法開啟備份，連我們也無法。請妥善保管密碼。
