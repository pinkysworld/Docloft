三步建立井然有序的档案

  1. 1

    拖入文档

    通过拖放或整个文件夹添加 PDF、扫描件和手机照片。Docloft 会校验副本并识别重复文件。

  2. 2

    检查并整理

    离线识别文字，检查建议的类型、日期和发件人，并添加标签。保存什么由您决定。

  3. 3

    查找并记住

    可按词语开头搜索，也可不带重音符号搜索。添加期限，并选择 Windows 通知的提前天数。

重要功能，触手可及

费用一目了然

您的合同每月和每年的费用，以及未来 90 天内可以解约的合同。

一分钟生成解约函

含合同编号和日期，可直接检查、复制或通过电子邮件发送。只有您自己发送的内容才会发出。

期限一目了然

解约日、合同到期、保修、付款和失效日期：查看已逾期的事项以及接下来的 30 天。

带模板的解约计算器

合同到期日减去通知期，即得到最晚解约日期。手机、电力或保险模板会预填常见数值，由您对照合同核对。

提醒，手机上也能收到

可自选提前多久发送 Windows 通知。始终保持最新的日历文件，可把期限同步到 Outlook 和手机。

离线文字识别与搜索

Windows OCR 让扫描件和照片可被搜索，也支持词语开头和不带重音符号的写法。

您的档案始终属于您

常见问题

Docloft 多少钱？

在 Microsoft Store 一次性购买 24,99 €，无订阅，包含版本 1 的所有更新。退款遵循 Microsoft Store 的条款。

我的原件会保留吗？

会。Docloft 保存一份经过校验的副本，原始文件保持不变，仍在原来的位置。

我的文件存储在哪里？

本地存储在您电脑上的 %LOCALAPPDATA%\MinhStudios\Docloft 下。文档副本是磁盘上的普通文件，没有云同步。

文字识别是如何工作的？

它借助 Windows OCR 和已安装的 Windows 语言包在本地运行。已安装的 Tesseract 可作为备用方案。

应用关闭时会显示提醒吗？

即使应用已关闭，Windows 也可以显示已安排的提醒。请启用 Windows 通知。在 400 天内最多安排 200 个提醒时间；请定期打开应用以更新计划。日期来自您的输入，请自行核对。

Docloft 会检查我的解约通知期吗？

不会。应用保存您输入的信息，并据此计算。它不会检查法定期限、合同条款或保管义务，也不提供法律或税务建议。

可以加密备份吗？

可以，使用密码（AES-256）加密，每周自动备份也支持。没有密码，任何人都无法打开备份，包括我们。请妥善保管密码。
